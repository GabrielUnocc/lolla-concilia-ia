Para realizar a conciliação de forma manual:

1 - Seleção de Títulos

Selecione dois ou mais títulos até que a cor do mesmo seja VERDE.

Enquanto a cor for LARANJA significa que os valores não estão de acordo.

2 - Realizando a Conciliação

Uma vez que estiver tudo certo o botão Conciliar aparecerá acima dos registros.

Clique no botão para fazer a conciliação.

3 - Finalizando / Observações

Caso alguma conciliação seja feita de forma equivocada, a mesma poderá ser corrigida na próxima etapa.

Os títulos restantes serão desvinculados automaticamente ao finalizar.
