# Protótipo visual (histórico)

Primeira simulação da ideia, com dados fictícios. Abra os arquivos direto no navegador.

| Arquivo | O que mostra |
|---|---|
| `conciliacao_ia_simulacao.html` | Tela no estilo do IXC: seleção de linhas (verde quando bate, laranja quando não), botão Conciliar, totais e painel da IA com 4 cenários (lote, duplicado, só no banco, só no IXC) |
| `contexto_ia_simulacao.html` | Tela de contexto da IA: regras editáveis com versões, dados lidos do IXC, o texto completo enviado à IA e o histórico de análises |

Substituído pelo [`mvp/`](../../mvp/) e pela [extensão](../../extensao/lolla/).
